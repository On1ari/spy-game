# 🕵️ Игра в шпиона - Brawl Stars Edition (Online)

Онлайн мультиплеер игра в шпиона с персонажами из Brawl Stars. Играйте с друзьями через интернет с любых устройств!

## 🎮 О игре

Социальная игра, где игроки делятся на шпионов и мирных жителей:
- **Шпионы** не знают загаданного персонажа и должны его угадать
- **Мирные жители** знают персонажа и должны вычислить шпионов, не выдав персонажа
- Игроки обсуждают, задают вопросы и голосуют

## ✨ Возможности

- 🌐 **Онлайн мультиплеер** - играйте с друзьями через интернет
- 🔗 **Комнаты с кодами** - создайте комнату и поделитесь 6-значным кодом
- 🔄 **Автоматическое переподключение** - не потеряете прогресс при разрыве связи
- 🎭 **Автоматическое распределение ролей** на сервере
- 🔒 **Защита приватных данных** - роли игроков хранятся на сервере
- 👥 **Real-time синхронизация** - все действия моментально видны всем игрокам
- ✅ **Зачеркивание игроков** и персонажей
- 📱 **Адаптивный дизайн** для мобильных и десктопов
- 🎨 **Современный UI** с градиентами и анимациями

## 🚀 Быстрый старт

### Предварительные требования:
- Node.js 20+ и npm

### 1. Установка зависимостей:
```bash
npm install
```

### 2. Настройка переменных окружения:
Скопируйте `.env.example` в `.env.local`:
```bash
cp .env.example .env.local
```

Содержимое `.env.local`:
```env
NEXT_PUBLIC_WS_URL=ws://localhost:3001
WS_PORT=3001
```

### 3. Запуск в режиме разработки:

**Вариант A: Запустить всё одной командой** (рекомендуется)
```bash
npm run dev:all
```

**Вариант B: Запустить отдельно**
```bash
# Терминал 1 - WebSocket сервер
npm run dev:server

# Терминал 2 - Next.js приложение
npm run dev
```

### 4. Открыть в браузере:
- Frontend: http://localhost:3000
- WebSocket: ws://localhost:3001

### Сборка для продакшна:
```bash
npm run build
npm start              # Next.js сервер
npm run start:server   # WebSocket сервер (в отдельном терминале)
```

## 🌐 Развертывание в интернете

### Вариант 1: Vercel (Frontend) + Railway (Backend) - Рекомендуется

#### Frontend на Vercel:
1. Загрузите проект на GitHub
2. Импортируйте проект в [Vercel](https://vercel.com)
3. Установите переменную окружения:
   - `NEXT_PUBLIC_WS_URL` = `wss://ваш-сервер.railway.app` (URL вашего WebSocket сервера)
4. Deploy!

#### Backend на Railway:
1. Создайте новый проект на [Railway](https://railway.app)
2. Подключите GitHub репозиторий
3. Настройте:
   - **Build Command**: `npm install`
   - **Start Command**: `npm run start:server`
4. Добавьте переменную окружения:
   - `WS_PORT` = `3001`
5. Deploy!
6. Railway предоставит публичный URL - используйте его в `NEXT_PUBLIC_WS_URL` на Vercel

**Важно**: В production используйте протокол `wss://` (не `ws://`).

### Вариант 2: VPS (Digital Ocean, AWS, etc.)

```bash
# На сервере
git clone ваш-репозиторий
cd spy-game
npm install
npm run build

# Установите PM2 для управления процессами
npm install -g pm2

# Запустите оба сервера
pm2 start npm --name "spy-game-ws" -- run start:server
pm2 start npm --name "spy-game-app" -- start
pm2 save
pm2 startup
```

Настройте Nginx как reverse proxy для WebSocket и HTTP.

### Переменные окружения для production:

| Переменная | Описание | Пример |
|-----------|----------|--------|
| `NEXT_PUBLIC_WS_URL` | URL WebSocket сервера | `wss://server.com` |
| `WS_PORT` | Порт WebSocket сервера | `3001` |

## 🏗️ Архитектура

### Технологический стек:
- **Frontend**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS
- **Backend**: Node.js WebSocket Server (библиотека `ws`)
- **Архитектура**: Client-Server с WebSocket для real-time синхронизации

### Как работает мультиплеер:
1. **WebSocket сервер** управляет комнатами и игровым состоянием
2. **Клиенты** подключаются через WebSocket и получают обновления в реальном времени
3. **Критические действия** (раздача ролей, старт игры) выполняются на сервере
4. **Публичное состояние** отправляется всем игрокам
5. **Приватное состояние** (роль + персонаж) каждый игрок получает отдельно

### Защита приватных данных:
- ✅ Информация о том, кто шпион, хранится только на сервере
- ✅ Каждый игрок получает только свою роль и персонажа
- ✅ Клиент не может получить данные о ролях других игроков
- ✅ Назначение ролей происходит на сервере

## 🎯 Как играть

1. **Создайте комнату**: один игрок создает комнату и получает 6-значный код
2. **Пригласите друзей**: поделитесь кодом или ссылкой
3. **Дождитесь игроков**: минимум 3 игрока для старта
4. **Начните игру**: хост нажимает "Начать игру"
5. **Играйте**: обсуждайте, задавайте вопросы, зачеркивайте персонажей и игроков
6. **Голосуйте**: определите, кто шпион!

## ⚠️ Ограничения и известные проблемы

### Ограничения:
1. **Масштабируемость**: Один сервер поддерживает ограниченное количество одновременных игр
2. **Персистентность**: Комнаты хранятся в памяти, при перезапуске сервера теряются
3. **Очистка**: Пустые/неактивные комнаты удаляются через 60 минут

### Решение проблем:

**WebSocket не подключается:**
- Проверьте, запущен ли WebSocket сервер (`npm run dev:server`)
- Убедитесь, что порт 3001 не занят
- Проверьте переменную окружения `NEXT_PUBLIC_WS_URL`

**Ошибка "Room not found":**
- Комната могла быть удалена из-за неактивности (60 минут)
- Создайте новую комнату

**Игроки не видят обновления:**
- Проверьте статус подключения (зеленая точка возле имени)
- Обновите страницу для автоматического переподключения
